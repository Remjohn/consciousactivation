# Production Definition of Done

CAE is ready for real supervised operational testing only when all of the following are true:

1. At least one real Program is discoverable and runnable through the Program control surface.
2. Program state is durable, resumable, and externally inspectable.
3. A Program can compose an Agent Team, Skills, Sub-agents and deterministic Operations.
4. Four Authority Lanes remain separate in execution and evidence.
5. Skills are loaded JIT from governed packages and maturity is enforced.
6. Hooks guarantee key invariants rather than relying on prose.
7. CAE typed operations remain the mutation boundary.
8. Artifacts and receipts are traceable to Program/State/Operation.
9. Workspace scope is enforced through state, retrieval, caches and background jobs.
10. One real research set can enter the curated knowledge layer and become usable by CAE reasoning.
11. One real Audience + Guest context can produce a collision hypothesis and Interview Brief.
12. One real interview can produce authenticated evidence and downstream editorial candidates.
13. At least one production artifact can be compiled, rendered and operator-approved.
14. Operator can inspect Programs, Artifacts and Chat.
15. E3/E4 tests include false-proof/adversarial cases.
16. Phase 4 acceptance evidence is recorded and CURRENT.md is synchronized.
17. Remaining limitations, if any, are explicitly non-critical and accepted by the operator.

No "production ready" claim may be based only on passing unit tests or successful agent messages.
