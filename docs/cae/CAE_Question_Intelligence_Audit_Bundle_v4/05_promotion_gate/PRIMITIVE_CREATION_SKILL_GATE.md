# Question Primitive Creation Skill — GATED

This skill is intentionally non-executable until ALL 12 Question Heritage Audits are `OPERATOR_ACCEPTED`.

## Preconditions
- 12 audit artifacts exist.
- Each audit has verified source-read status.
- Each audit has an operator acceptance record.
- No unresolved `SOURCE_ACCESS_FAILURE` exists.
- Cross-book clustering corpus is complete.
- Existing taxonomy has been reviewed for book-discovered novelty.

## Only then
Perform cross-book mechanism clustering, merge/split candidate mechanisms, form the canonical Question taxonomy, and propose Question Primitive YAMLs. Every primitive must retain source lineage to the accepted audits.

## Prohibited
Never manufacture a primitive to complete a numeric quota. Never convert one book's isolated advice directly into canonical primitive law merely because it is useful.
