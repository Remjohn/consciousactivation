# Gemini Book-Audit Execution Law

Gemini is an executor of a bounded research mandate, not the owner of the Question Intelligence ontology.

For each book Gemini MUST:

1. locate the actual source file;
2. verify it is complete enough to read as the assigned source;
3. run the PDF-to-Markdown tool when only PDF is available;
4. inspect the resulting Markdown for page/section continuity;
5. read the full book rather than sampling selected chapters;
6. load the relevant CAE/CCP architecture references;
7. write one complete audit file;
8. keep source claims separate from CAE interpretation;
9. stop if evidence is insufficient rather than inventing details;
10. not create or modify primitive registry YAMLs;
11. not modify production runtime code;
12. report exact paths and evidence in the completion record.

The agent may create research-only support artifacts (source normalization logs, reading manifests, chapter maps, notes), but only the audit file is the book-level deliverable.

The mandate is successful only when the audit exists, the source-read check passes, and the operator gate receives the result.
