# Phase 2 — Pilot Runtime Requirements

One real Program must prove:
- Program discovery;
- package compilation;
- one Harness;
- at least two Authority Lanes;
- at least one Agent Team;
- at least one Sub-agent;
- at least two Skills;
- typed operations;
- pre-tool deterministic hook;
- state-transfer/completion check;
- artifact + receipt persistence;
- operator gate;
- crash/resume;
- causal trace from request to final artifact.
