# Worked Example — Bounded Adaptive Routing

## Spine requirement

Acquire:

1. origin/initial state;
2. triggering event;
3. decision;
4. consequence;
5. changed understanding;
6. changed behavior.

## Candidate frontier after an answer

Observed answer: “I realized I was exhausted, so I decided to leave.”

Candidate next moves:

1. deepen — “What happened that made you realize you were exhausted then, specifically?”
2. verify — “What did you actually change after leaving?”
3. reconcile — “You said leaving was obvious by then, but earlier you described staying as the only reasonable option. What changed between those two points?”
4. broaden — “What else was happening around you at the time?”
5. advance — move to consequence if the required evidence is already sufficient.

The runtime must rank/select deterministically using the current answer observation and unresolved requirements. The frontier is bounded; it is not an unconstrained brainstorm.
