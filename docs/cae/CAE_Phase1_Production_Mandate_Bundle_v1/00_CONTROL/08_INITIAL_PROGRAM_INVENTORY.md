# Canonical CAE Program Inventory — Phase 1 Baseline

This is a planning baseline. M02 validates it against the live repository.

A Program is an operator-addressable unit of supervised work; it is not automatically
a Service, Skill, Agent, Harness or database object.

Every row must ultimately contain:
purpose, operator trigger, scope, inputs, preconditions, upstream/downstream,
existing service/route, typed operations, Harness readiness, Agent Team,
Skills, Sub-agents, tools/MCP, hooks/extensions, state machine, gates,
artifacts, receipts, runtime evidence, production status, gap, authority owner.

Initial lifecycle families:
- Workspace/Client
- Guest
- Audience
- Research/Knowledge
- Activation/Collision
- Interview
- Evidence
- Editorial
- Production
- Release
- Learning
- Operator Control

Create Workspace; Configure Workspace; Operator Access; Guest Setup; Guest Genesis;

Audience State Update; Research Workspace; Source Acquisition; Source Verification;
Knowledge Extraction; Concept Canonicalization; Entity Canonicalization; Knowledge Clustering;
Research Signal; Research-to-Context; Audience×Guest Resonance; Matrix of Edging;
Collision Discovery; Hypothesis Portfolio; Interview Preparation; Interview Brief; Run Interview;
Answer Observation; Interview Ingestion; Semantic Segmentation; Semantic Attribution;
Content Candidate Formation; Candidate Scoring; Candidate Clustering; Operator Selection;
Editorial Storyboard; Semantic Program; Script Program; Visual Prompt Program;
Carousel Production; SuperVisual Production; Animation Production; Video Edit Program;

Outcome Analysis; Audience State Learning; Guest State Learning; Harness Learning;
Programs Control; Artifacts Control; Chat Control; Program Repair; Failure Review.
