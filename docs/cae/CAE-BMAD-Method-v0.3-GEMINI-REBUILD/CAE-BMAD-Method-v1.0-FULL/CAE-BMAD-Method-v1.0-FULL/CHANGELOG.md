## 1.0.0 — Full Bundle

The previous v0.1/v0.2 bundles are superseded.

The bundle now:

- treats the actual BMAD repository as a mandatory base
- preserves the original BMAD source tree
- validates the original core/BMM families
- provides full BMAD-shaped CAE skills
- provides `SKILL.md`, `steps/`, `assets/`, `references/`, and customization files for major CAE workflows
- provides installation/bootstrap scripts
- provides a mandatory-upstream manifest
- provides source-lineage and operating-level governance
- provides research corpus controls
- provides CAE artifact templates and validation
- provides explicit handoff into CAE Programs/Workflows/Agents/Skills/Harnesses/Sessions/Runtime
