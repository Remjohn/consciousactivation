# Story Template

## Purpose

Story template.

## CAE Requirements

This file is a real working companion artifact, not a placeholder.

It must preserve:

- source traceability
- product-vs-runtime distinction
- explicit state
- dependencies
- acceptance
- failure/recovery
- implementation references
- operator decision boundaries
- evidence

## Usage

Read this file at the step that explicitly references it from the parent skill.
Do not load unrelated companion files in advance.

## Minimum content standard

The companion must be detailed enough to be directly used to produce the corresponding artifact.
Do not replace it with a two-paragraph summary.

## Review

Before acceptance, verify that every required section has concrete content or an explicit `MISSING`,
`PROPOSED`, `DEFERRED`, or `NOT_APPLICABLE` disposition.
