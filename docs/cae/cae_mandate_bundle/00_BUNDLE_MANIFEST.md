## Execution rule

Each mandate is independently executable and has its own boundary. Gemini must receive:

1. the specific mandate;
2. all listed references;
3. the 200–300 word activation prompt in that mandate;
4. the current control-state record;
5. explicit operator authorization for that mandate.

A mandate does **not** authorize the next mandate unless its own operator gate is passed.

## Non-negotiable architecture laws

- Role precedes schema.
- Evidence precedes inference.
- Canonical definitions are versioned; operational state is dynamic; evidence is immutable; derived artifacts are reproducible.
- PostgreSQL/Supabase is the intended CAE operational authority unless an aggregate-specific authority decision says otherwise.
- Agents use typed semantic operations rather than arbitrary database writes.
- SDA governs semantic direction and geometry; SFL governs perceptual modulation; neither may silently replace the other.
- A score is not evidence.
- A passing automated test is not proof beyond its declared fidelity.
- Operator selection is a first-class editorial event and learning signal.
- Selected reusable assets receive deep annotation; raw transcripts are evidence, not automatically production assets.
- Human evidence is required before the system earns the right to render a human-authored activation outcome.
- Anti-centroid and reality-contact evaluation remain active at every relevant stage.

## Delivery modes

The program intentionally supports bounded parallelism. Read-only investigations may run in parallel when they have one designated integration owner. Shared state, migrations, registry changes, and authority decisions remain sequential and operator-gated.
