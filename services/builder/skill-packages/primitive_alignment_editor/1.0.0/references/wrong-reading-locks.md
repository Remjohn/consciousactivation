1. **Spatial Lock Isolation:** Spatial layout locks (`wrong_reading_locks`) belong exclusively to `visual_syntax_composition_compiler`. 3. **No Noun Laundering:** The alignment process must not retain specimen-specific proper nouns, character names, or episode titles in meaning-plane locks.

4. **Lineage Preservation:** Immutable semantic lineage refs (`identity_dna_ref`, `source_premise_ref`, etc.) must pass through byte-identical.
