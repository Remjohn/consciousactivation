# Wrong-Reading Locks — Visual Syntax Composition Compiler

## Skill Self-Governance Locks

1. **Do Not Invent Primitives:** The compiler must never invent custom primitive types outside the canonical list (`text_block`, `image_region`, `grid_cluster`, `comparison_pair`, `badge`, `number_label`, `icon_row`, `caption_plate`, `callout_arrow`, `flow_diagram`). Content variations must be expressed through attribute ranges.

2. **Do Not Weaken Harness Locks:** Every wrong-reading lock in the input harness definition must produce at least one explicit spatial or typographic constraint in the output specification.

3. **Do Not Mutate Lineage:** Semantic input references (`identity_dna_ref`, `source_premise_ref`, etc.) must pass through unchanged.

4. **Do Not Hardcode Content:** Layout rules must specify geometry ranges and layout modes, not specific brand names, text copy, or image URLs.
