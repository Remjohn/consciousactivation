# Visual Prompt + Asset Annotation Program Governance (CAE.md)

## Authority & Non-Negotiables
1. **Four-Lane Authority Separation:**
   - `COMMANDER`: Admits programs, conducts backend-authoritative operator approvals, and signs audit receipts.
   - `HUNTER`: Extracts visual requirements and scene obligations directly from spoken evidence.
   - `ANALYST`: Curates media asset annotations, validates rights clearances, and verifies SHA-256 byte checksums.
   - `COMPOSER`: Compiles visual prompt specifications and provider-neutral demand contracts.
2. **Lineage Integrity:**
   - Every visual demand MUST cryptographically reference upstream `EvidenceSegment` quotes and turn hashes.
   - Tampered evidence hashes fail closed immediately.
3. **Anti-Synthetic Defense:**
   - Synthetic or unverified mock content cannot be promoted or approved for production.
4. **Wrong-Reading Locks:**
   - Locks declared in `SemanticProgram` MUST be preserved and baked into negative prompt constraints.
5. **No Flat Float State Serialization:**
   - All confidence scores, basis points, coordinates, and tolerances MUST use integer/basis-points representation.
