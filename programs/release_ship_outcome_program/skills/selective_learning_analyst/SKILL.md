# Selective Learning Analyst Skill

## Overview
This skill analyzes historical performance memory to synthesize advisory calibration proposals.

## Execution Rules
1. Aggregate recurring failure modes or systematic prediction offsets across sessions.
2. Formulate advisory `LearningProposal` with concrete calibration recommendations.
3. Every proposal strictly sets `requires_operator_ratification: true`.
4. Direct mutation of canonical ontology is strictly prohibited (`OntologyMutationViolationError`).
