# Conscious Activation Engine — Phase 2 Bundle

## Phase
Phase 2 — World Intelligence & Contextual State

## Objective
Build the upstream intelligence substrate that represents the human and environmental reality from which later relational reasoning, edging, interview activation, semantic composition, and realization are derived.

## Core doctrine
The engine must not treat Audience or Guest as static profiles. They are persistent entities with attached schemas, evidence, state histories, and evolving semantic structures.

Context Premise is an evidence-bearing subsystem, not the complete Audience ontology.

Research Signal is immutable evidence, not truth merely because it was retrieved.

Tension/Webhook is a derived, stateful activation object. It is not synonymous with a topic, hook, or mood.

Mood/Affective State is a receptivity condition and must remain distinct from semantic tension.

## Module boundary
Phase 2 owns:
- Audience World
- Guest World
- Cultural / Research World
- Context Premise evidence model
- Audience/Guest schema representations
- Contextual and audience/guest state models
- Tension/Webhook derivation
- signal confirmation and evidence weighting
- audience maturity and affective state representations
- current semantic load / active-context state
- world-intelligence history and memory

Phase 2 does NOT own:
- Guest↔Audience congruence / Trigger Matching as a full relational engine
- Matrix of Edging execution
- Primitive coalition selection
- SFL realization
- CCF semantic compilation
- CMF scene/render execution

## Phase gate
Before Phase 3, the project should have:
1. Brownfield mappings for Audience/Guest/Context Premise/Research/State structures.
2. Canonical Object Constitutions for all Phase 2 owned objects.
3. A provenance and evidence-confidence model.
4. A temporal state/event model.
5. A first storage design using SQL + JSONB + vectors + event records.
6. Derived Webhook/Tension rules with explicit confirmation thresholds.
7. Authorized semantic query functions for world intelligence.
8. Technical specifications for the highest-priority FRs.
