# FR-CA-02-004 — Audience Schema and Semantic Representation

## Requirement
Audience Schema MUST model persistent relational structure among beliefs, identities, desires, fears, coping patterns, status, safety, and other stable semantic dimensions.

## Constraints
Schema definitions are versioned structural models, distinct from observations and state estimates.

## Implementation Principle
Schema inference MUST preserve evidence lineage and uncertainty.

## Acceptance Criteria
- Canonical identity/ownership is explicit.
- Object Constitution fields are defined or marked pending.
- Provenance and lifecycle are testable.
- No silent flattening of evidence into unsupported canonical claims.
- Brownfield status is recorded before replacement.
