# FR-CA-02-003 — Context Premise Evidence Model

## Requirement
Context Premise MUST be represented as structured evidence-bearing observations across the twelve retained categories, not as one opaque profile blob.

## Constraints
Each observation MUST preserve category, language, source, provenance, confidence, scope, and temporal context.

## Implementation Principle
Original audience language MAY be retained in structured prose fields when it carries signal; canonical semantics remain separately addressable.

## Acceptance Criteria
- Canonical identity/ownership is explicit.
- Object Constitution fields are defined or marked pending.
- Provenance and lifecycle are testable.
- No silent flattening of evidence into unsupported canonical claims.
- Brownfield status is recorded before replacement.
