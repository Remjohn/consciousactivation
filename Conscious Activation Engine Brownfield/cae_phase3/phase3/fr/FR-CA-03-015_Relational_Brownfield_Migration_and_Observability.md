# FR-CA-03-015 — Relational Brownfield Migration and Observability

Audit the existing consciousactivation-main implementation and map:
- existing relation code;
- legacy Trigger Matching;
- Context Reasoning implementations;
- affinity/semantic guards;
- schemas and registries;
- duplicated objects;
- orphaned relations;
- missing state models;
- missing provenance;
- runtime gaps.

No migration plan may assume greenfield implementation without repository evidence.
