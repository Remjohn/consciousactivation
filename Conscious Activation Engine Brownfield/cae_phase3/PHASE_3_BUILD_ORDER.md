# Phase 3 Build Order — Relational Intelligence, Congruence & Context Reasoning

## Stage 1 — Brownfield relational audit
Inventory existing Guest, Audience, Trigger Matching, Context Reasoning, affinity, semantic guard, primitive crosswalk, and edging implementations.

## Stage 2 — Relational object constitutions
Define object-specific constitutions for relation, assessment, plan, candidate, state, observation, and receipt classes using the Phase 1 constitutional framework.

## Stage 3 — Relation ontology and taxonomy
Define relation types, directions, temporal semantics, evidence grades, relation states, and adjacency classes.

## Stage 4 — Congruence model
Decompose Guest ↔ Audience congruence into explicit axes. Preserve the previous four-axis Trigger Matching architecture as a candidate model, but represent it as configurable relation logic rather than an unquestioned universal truth.

## Stage 5 — Schema-crossing engine
Determine how Audience Schema, Guest Schema, Context Premise, invariants, states, and cultural signals cross without collapsing distinct ontological objects.

## Stage 6 — Context Reasoning planner
Implement intent → schema link → relation retrieval → subproblem decomposition → reasoning plan → typed result → validation → error classification → repair.

## Stage 7 — Pressure field
Generate candidate pressure fields from relational evidence. Do not let Matrix of Edging silently reconstruct missing upstream evidence.

## Stage 8 — Matrix of Edging handoff
Define the exact contract by which broad primary signals are selected from an upstream pressure field.

## Stage 9 — Receipts and explainability
Persist relation evidence, weights, decision paths, rejected candidates, and contradiction signals.

## Stage 10 — Technical specification convergence
Prioritize relational storage, query functions, planner contracts, congruence evaluation, and edging handoff specifications.

## Phase gate
A Phase 3 build is accepted only when a human operator can inspect a relation candidate and answer:

- Why do these objects relate?
- Which evidence supports it?
- Which dimensions matched?
- Which dimensions did not?
- Is the relation current or historical?
- What alternative interpretations were considered?
- What downstream decisions is the relation legally allowed to influence?
