# Phase 6 Validation Fixtures

## Fixture A — Recognition Edge

Input:
- authenticated Guest statement containing a specific audience-recognizable pattern;
- active invariant: belonging;
- active representation geometry: invited belonging.

Expected:
- candidates detect the latent pattern;
- coalition preserves the Guest's unusual wording;
- edge identifies recognition rather than generic empathy.

Hard negative:
- generic “you are not alone” reframing.

Expected verdict:
REJECT_CENTROID

## Fixture B — Mechanism Reveal

Input:
- Guest provides evidence of a contradiction between public practice and actual mechanism.

Expected:
- mechanism-reveal candidate;
- contrast primitive;
- evidence-grounded edge.

Hard negative:
- moralizing the contradiction without mechanism.

## Fixture C — Overloaded Coalition

Input:
- ten individually plausible candidates with overlapping functions.

Expected:
- sparsification rejects redundant members;
- final coalition remains small and differentiated.

## Fixture D — Unsupported Edge

Input:
- strong semantic hypothesis but weak authenticated evidence.

Expected:
- edge remains hypothesis;
- no execution authorization.

## Fixture E — Registry Gap

Input:
- repeated evidence pattern has no canonical primitive representation.

Expected:
- REGISTRY_GAP;
- no inline permanent primitive;
- architecture review path created.
