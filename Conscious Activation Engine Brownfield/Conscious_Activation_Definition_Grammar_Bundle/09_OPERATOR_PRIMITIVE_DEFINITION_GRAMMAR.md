# Operator / Primitive Definition Grammar Protocol

## Artifact class

`OPERATOR`

## Purpose

Defines a canonical, evidence-grounded transformation capability that may be activated against an admissible input field.

## Definition grammar

Use:

**Transformation + Substrate + Activation Conditions + Expected Direction + Operating Dimensions + Admissible Range + Anti-Patterns + Adjacent Operators + Evidence Basis + Runtime Effect**

## Mandatory distinction

`Primitive` is the canonical operator definition.  
`PrimitiveActivation` is the runtime state created when that operator is invoked.

Runtime activation MUST NOT mutate the Primitive definition.

## Required source integrity

Where the registry requires it, a Primitive MUST preserve dual-source evidence:

- internal audit source
- direct source/book reference

## Examples

`MeaningPrimitive`, `ExperiencePrimitive`, other governed transformation operators.

## Hard negatives

- primitive defined as a style adjective
- primitive defined as output content
- primitive defined as a format
- primitive activation written back into canonical definition
- unsupported operator added without evidence

## Validation focus

- definition fidelity
- range validity
- activation eligibility
- compatibility
- antagonism
- routeability
- provenance
