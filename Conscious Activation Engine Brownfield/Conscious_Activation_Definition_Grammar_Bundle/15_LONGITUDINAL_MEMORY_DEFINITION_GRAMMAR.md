# Longitudinal Memory Record Definition Grammar Protocol

## Artifact class

`LONGITUDINAL_MEMORY`

## Purpose

Defines persistent memory of change, recurrence, outcomes, or evolution across multiple events and time intervals.

## Definition grammar

Use:

**Tracked Subject + Memory Phenomenon + Observation Sequence + Time + Aggregation Rule + Persistence Meaning + Update Rule + Confidence**

## Examples

`SemanticEvolutionRecord`, `PerceptualEvolutionRecord`, `ImprintHistoryRecord`, `AudienceFamiliarityTrace`, `LoopPressureHistory`.

## Definition must establish

- what is being tracked
- what constitutes a meaningful change
- how observations are aggregated
- what history is retained
- what may decay
- what triggers reevaluation
- how memory informs future planning

## Hard negatives

- memory reduced to current state
- memory overwriting raw events
- historical pattern treated as permanent law
- longitudinal trend inferred from insufficient observations
