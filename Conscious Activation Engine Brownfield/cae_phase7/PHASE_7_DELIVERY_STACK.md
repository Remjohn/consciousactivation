# Phase 7 — Delivery Stack and Composition Depth

## Purpose

Phase 7 needs an intermediate delivery model between “meaning” and “scene.” This is where SFL and depth profiles cooperate.

## Delivery stack

```text
Edge Product
  ↓
Archetype Container
  ↓
SFL Function Stack
  ↓
Composition Depth Profile
  ↓
Perceptual Effect Profile
  ↓
Semantic Program
```

## Composition depth profiles

Canonical profile classes:

### RepetitionWithVariation
Preserves recognition while preventing mechanical repetition.

### LayeredInterpretation
Allows an artifact to operate at more than one interpretive depth without forcing every layer to be explained.

### RhythmicStructure
Controls temporal or sequential pacing at the semantic-program level.

### StrategicAmbiguity
Preserves productive incompleteness where explicit resolution would reduce meaning, while forbidding ambiguity that merely hides unsupported claims.

## Boundary

Depth profiles do not decide:
- camera coordinates
- animation implementation
- edit points
- media asset IDs
- soundtrack selection

They establish constraints for those downstream systems.

## Anti-centroid implication

Depth must not become “more complexity.”
A valid depth profile increases meaningful interpretability, memorability, rhythm, or recognition without adding ornamental density.
