# Phase 7 Acceptance Tests

## AT-01 — Edge preservation
Given a validated Edge Product, produce multiple eligible archetypes. Every passing program must preserve the edge ID and invariant lineage.

## AT-02 — Historical benchmark does not overrule semantic fit
A historically high-performing but semantically incompatible archetype must be rejected.

## AT-03 — Canonical SFL enforcement
An unknown SFL function ID must fail compilation.

## AT-04 — SFL canonical/runtime separation
Changing a runtime stack must not mutate canonical function definitions.

## AT-05 — Director Note fidelity
A high-priority human directive must appear in typed form and survive into SemanticProgram constraints.

## AT-06 — Anti-centroid
The system must reject a program that removes edge specificity and replaces it with generic motivational framing without authorization.

## AT-07 — False depth
Adding more symbols, repetition, ambiguity, or mood words without measurable semantic/perceptual gain must fail.

## AT-08 — Phase boundary
Concrete scene asset IDs or render coordinates must be rejected.

## AT-09 — Reproducibility
Same snapshots + same directives + same controlled parameters must reproduce the same contract/IR decision trace within declared exploration variance.

## AT-10 — Repair
A typed error must cause the appropriate targeted repair, not blind regeneration.
