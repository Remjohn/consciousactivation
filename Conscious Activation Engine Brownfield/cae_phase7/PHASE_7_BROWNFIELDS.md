# Phase 7 Brownfield Integration

## Existing architecture carried forward

Phase 7 must integrate with the established Conscious Activation architecture rather than replace it.

### Existing canonical sources to preserve

- Conscious Primitives registry and family classification
- SDA ontology / grammar / runtime packets
- Matrix of Edging
- CCF archetype inventory and retained archetype families
- SFL proposed/canonical taxonomy and function layer
- JIT Skill Compiler doctrine
- Psychological routing / mood state architecture
- Context Premise / Audience State / Guest State substrates
- Anti-centroid / anti-draft doctrine

## Brownfield audit questions

1. Which archetype definitions already exist as YAML?

4. Are archetype contracts typed or prose-only?
5. Are SFL crosswalks explicit or embedded in prompts?

## Migration law

Do not “clean up” the brownfield system by deleting historical structures before lineage is mapped. First establish canonical identity, aliases, adapters, and deprecation status.
