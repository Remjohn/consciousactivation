### Constitutional laws

1. **Edge Authority:** Phase 7 may only structurally realize a validated Edge Product; it may not invent a new semantic force to justify a preferred archetype.
2. **Meaning Before Container:** an archetype is selected because it is a valid carrier for the current semantic force, not because it is fashionable or convenient.
3. **Container Is Not Format:** an ArchetypeContainer defines structural/cognitive organization; platform format remains downstream.
4. **SFL Is Canonical:** SFL families, function definitions, and alignment policies are canonical assets. A runtime `SubliminalFunctionStack` is dynamic and context-bound.
5. **SFL Does Not Redefine Meaning:** SFL changes perceptual delivery conditions; it must not silently alter invariant direction, edge identity, or representation geometry.
6. **No Premature Rendering:** Phase 7 does not select concrete scenes, shots, crops, keyframes, transitions, music tracks, or executable media operations.
7. **Human Director Notes Are First-Class Directives:** human intent may enter as prose and must be compiled into typed directives; it must not remain an unbounded prose override.
8. **Anti-Centroid Law:** generic smoothing, corporate-softening, motivational defaulting, and unnecessary explanatory expansion are defects unless explicitly authorized by a contract.
9. **No RLHF-Style Safety Insertion:** safety, ethics, legality, and policy constraints may be enforced where actually applicable, but the architecture must not invent permission/censorship constraints merely because an output is intense, controversial, asymmetrical, or emotionally charged.
10. **Typed Program Boundary:** all decisions leaving Phase 7 must be represented in a typed SemanticProgram/contract object with lineage, not only prose.
11. **Role Before Schema:** every canonical object must have a declared architectural role before its schema is finalized.
12. **Fail Closed, Not Bland:** unresolved structural uncertainty becomes a typed route/error/review state; it must never silently collapse the semantic force into generic copy.
