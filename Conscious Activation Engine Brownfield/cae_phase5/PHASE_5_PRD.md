# PRD-P05 — Human Interview, Authentication & Evidence Acquisition

## 1. Purpose

The Human Interview subsystem is the truth-acquisition layer of the Conscious Activation Engine. It transforms a governed activation opportunity into authenticated human source material without replacing the Guest's judgment with model inference.

## 2. Architectural claim

The interview is not merely a content interview. It is the compiler boundary at which a relational hypothesis is tested against a living human source.

The governing transition is:

`Activation Hypothesis → Question → Guest Response → Evidence → Authentication → Semantic Evidence Packet`

The system must preserve the difference between:

- what it hypothesized,
- what it asked,
- what the Guest said,
- what was extracted,
- and what the system inferred afterward.

## 3. Product outcome

A successful session yields high-density, first-party evidence that can safely feed Primitive Candidate generation and later CCF/CMF compilation.

## 4. Human-first contract

The system may:

- select what to ask,
- sequence follow-ups,
- ask for specificity,
- surface contradictions,
- request concrete examples,
- test whether a stated position changes under counterexample.

The system may not:

- answer the question for the Guest,
- insert a desired conclusion into the question,
- rewrite a Guest position into a stronger position and store it as evidence,
- manufacture emotional intensity,
- replace unusual wording with generic language before evidence preservation.

## 5. Runtime layers

1. Interview Brief Compilation
2. Question Planning
3. Turn Execution
4. Response Capture
5. Evidence Extraction
6. Authentication
7. Anti-Leading / Anti-Centroid Patrol
8. Evidence Packet Emission
9. Receipt / Lineage Update

## 6. Brownfield integration

Phase 5 consumes the existing Context Premise, Guest intelligence, Emotional DNA, Voice DNA, Negative Space, Phase 4 Matrix of Edging outputs, and current interview ingress. Existing transcript intelligence and authenticity machinery should be reused where present rather than duplicated.

## 7. Success criteria

- 100% downstream-eligible evidence has immutable lineage.
- No hypothesis is promoted to Guest truth without an explicit authentication decision.
- Original Guest wording remains retrievable.
- Question provenance is available for every response.
- Anti-leading and anti-centroid checks are recorded.
- Dynamic replanning can react to unexpected evidence.
