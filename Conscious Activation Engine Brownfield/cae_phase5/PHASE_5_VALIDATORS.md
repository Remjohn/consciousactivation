# Phase 5 Validators and Gates

## V1 — Provenance completeness
Every downstream evidence object must trace to an immutable response/span.

## V2 — Hypothesis separation
Phase 4 hypothesis text must remain distinguishable from Guest-originated evidence.

## V3 — Question integrity
Question contains no unsupported conclusion embedded as fact.

## V4 — Evidence specificity
High-value evidence should preserve concrete details where the source contains them.

## V5 — Interpretation boundary
Interpretations require explicit labels and must not overwrite source statements.

## V6 — Contradiction preservation
Contradictory evidence remains represented until resolved or explicitly classified.

## V7 — Anti-leading
Questions that materially contaminate answer space fail the gate and must be replanned.

## V8 — Anti-centroid
Derived text that systematically softens or genericizes Guest language fails unless there is a declared factual or structural reason for the transformation.

## V9 — Downstream authorization
Only evidence satisfying the consumer's declared authentication threshold enters the SemanticEvidencePacket.

## V10 — Receipt completeness
The complete lineage from activation event to emitted packet must be reconstructible.
