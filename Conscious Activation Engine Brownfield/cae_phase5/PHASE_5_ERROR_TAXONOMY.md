# Phase 5 Error Taxonomy

## Schema
- `SCHEMA_ERROR`
- `MISSING_REQUIRED_FIELD`
- `INVALID_STATE_TRANSITION`

## Relationship
- `RELATION_ERROR`
- `WRONG_GUEST_LINK`
- `WRONG_AUDIENCE_LINK`
- `ACTIVATION_LINEAGE_ERROR`

## Interview
- `QUESTION_GRAMMAR_ERROR`
- `QUESTION_SEQUENCE_ERROR`
- `LEADING_QUESTION_ERROR`
- `PRESUPPOSITION_ERROR`
- `QUESTION_REPETITION_ERROR`
- `EVIDENCE_TARGET_MISSING`

## Evidence
- `EVIDENCE_PROVENANCE_ERROR`
- `EVIDENCE_SCOPE_ERROR`
- `INTERPRETATION_AS_EVIDENCE`
- `INSUFFICIENT_SPECIFICITY`
- `CONTRADICTION_UNRESOLVED`
- `AUTHENTICATION_ERROR`

## Semantic
- `SEMANTIC_DRIFT`
- `CONTEXT_DRIFT`
- `TENSION_DRIFT`
- `MEANING_INFLATION`

## Anti-centroid
- `RLHF_CENTROID_SOFTENING`
- `GENERICIZATION`
- `CONTRADICTION_ERASURE`
- `CORPORATE_LANGUAGE_INJECTION`
- `EDGE_DILUTION`

## Runtime
- `CAPTURE_ERROR`
- `TRANSCRIPTION_ERROR`
- `PLANNER_ERROR`
- `VALIDATION_ERROR`
- `RECEIPT_ERROR`

Each error must carry: code, severity, object_id, stage, source, detection method, repair action, and whether human review is required.
