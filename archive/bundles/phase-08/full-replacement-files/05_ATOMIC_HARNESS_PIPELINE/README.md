# Atomic Harness Pipeline

The Atomic Harness Pipeline is the deterministic, development-only execution control plane for approved Atomic Harnesses. Phase 8 preserves the Phase 6 composition/media runtime and adds a bounded Pipeline → Delegation RC4 → VAE → Asset Result → Result Acknowledgement path.

## Phase 8 integration capabilities

- exact, non-forking consumption of `delegation-contracts@1.1.0-rc.4`;
- provider-neutral Visual Asset Demand compilation;
- preservation of Canonical Interview Source Package, Reaction Receipt, Expression Moment, semantic-program, Final Script, Primitive coalition, archetype coalition, and Activation Transfer references;
- explicit rejection of active Format 02 demands;
- Asset Result validation;
- separate Pipeline-owned Result Acknowledgement and downstream-consumption decision;
- no acquisition of VAE production strategy or AIR semantic authority.

## Preserved Phase 6 capabilities

- canonical `VideoEditProgram` and source-led A-roll lineage;
- word-boundary EDL and output-time mapping;
- FFmpeg source-led rendering;
- Remotion and HyperFrames binding manifests;
- Composition IR, semantic BBOX geometry, deterministic text measurement;
- SuperVisual, Carousel, and reusable animation-scene reference rendering;
- rendered evaluation and bounded repair planning.

## Development commands

```bash
python -m cmf_pipeline status --json

```

The VAE demo is executed through:

```bash
python -m cmf_vae --repo <repository-root> demo --output-dir <output-directory>
```

## Boundaries

AIR owns Activative meaning. Interview Expression owns source and reaction evidence. Builder owns Harness compilation. Pipeline owns execution programs, demand compilation, result validation, and acknowledgement. VAE owns visual production planning, capability routing, provider/runtime selection, evaluation implementation, and visual repair. Delegation owns transport lifecycle.

No real SAM3, Lucida, ComfyUI worker, or Google GNM execution is claimed. VAE Stage 5, Format 02, production authorization, and certification remain false.
