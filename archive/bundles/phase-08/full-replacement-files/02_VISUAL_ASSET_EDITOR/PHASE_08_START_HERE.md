# Phase 8 — Delegation and Visual Asset Editor Integration

Phase 8 adds a bounded development implementation of the VAE product boundary, exact
Delegation RC4 consumption, local content-addressed storage, an asynchronous SQLite queue,
worker leases and fencing, provider-neutral planning, Dynamic Workcells, a locked ComfyUI
graph compiler, reference segmentation/matting/materialization, optional external SAM3,
Lucida, and Google GNM command adapters, technical evaluation, bounded repair, OKF projection,
and a Control Tower read model.

This is development evidence only. It does not start production VAE Stage 5, activate
Format 02, certify an evaluator, or prove the external providers.
