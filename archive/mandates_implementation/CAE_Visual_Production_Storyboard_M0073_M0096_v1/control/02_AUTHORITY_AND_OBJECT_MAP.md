# Authority and Object Map

## Existing authoritative objects
- Semantic Program: semantic intent and meaning.
- Atomic Harness: bounded execution grammar and compilation.
- EditorialStoryboard: governed narrative storyboard authority.
- Composition IR: deterministic spatial representation.
- Asset Intelligence / AuthorityFirstRetrievalService: eligible media retrieval.
- VAE governance/contracts: downstream visual asset production.
- OpenChatCut: video runtime/editor authority only within native editing.
- CAS/state/receipts: state and evidence history.
- Design System: workspace-scoped canonical visual authority; derived brand context cannot compete with it.
