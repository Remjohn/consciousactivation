# CAE Visual Production / Storyboard Campaign M0073–M0096 v2

This is the executable mandate bundle for the post-M72 Visual Production / Evidence-First Storyboard campaign. It contains 24 mandates, each over 700 words and compliant with the CAE Mandate Authoring Protocol structure, including a 200–300 word activation prompt.

## Primary outcome

Build a CAE-native Storyboard and Evidence-First Visual Asset Studio capable of:
- visual asset research and playable candidate preview;
- fast candidate swap/selection with provenance;
- format-specific storyboard programs;
- Narrative Editing Grammar;
- Editorial Expression Calculus;
- Transformation Intent and Recipe;
- source-quality-aware transformation;
- operator visual inspection, correction and teaching feedback;
- Visual Chat;
- SAM3 speaker/subject tracking sessions;
- SuperVisual composition over BBOX/Pretext/Skia/Rough Notation;
- Carousel/Presentation runtime adapters;
- native OpenChatCut handoff;
- single-tab Studio runtime orchestration;
- partner-ready vertical-slice certification.

## Integration rule

External repositories are not merged as competing applications. Their behavior is extracted surgically, proven, isolated, and then composed into CAE-owned contracts.


## v2 Execution correction

This version explicitly implements the component-factory model: Authority Pack → isolated extraction/component bundles → contract/compatibility review → final puzzle assembly → certification. The campaign-supplied `AUTHORITY_PACK/` contains the Visual Production Update documents required by implementation mandates, so agents do not fail merely because those documents were not copied into the brownfield repository.
