# CAE Visual Production Update — v2

Updated 2026-09-10 after the external-repository architecture review.

## Core decision

The CAE visual production system is evidence-first and operator-centered:

`Evidence → Meaning → Format Storyboard Program → Narrative Editing Grammar → Editorial Expression Calculus → Transformation → Visual Asset Studio → Runtime`

## What changed in v2

- External repository adoption is explicitly **surgical and Functional-Requirement driven**.
- External repositories are classified as reference sources, isolated components, runtimes, primitives, or intelligence engines rather than treated as redundant full products.
- Asset Research / PlayPhrase-like candidate retrieval is explicitly a first-class **Asset Research Session** with playable previews, rapid swipe/keyboard comparison, accept/reject, replacement and governed promotion.
- A staged component-session workflow is defined for agents: map FR → inspect exact source files → review license/dependencies → clone/adapt minimally → prove behavior → integrate later.
- Visual editing remains evidence-first: retrieve → transform → compose → generate only when justified.
- Conscious E-Motion Editing Standards now include Narrative Editing Grammar + Editorial Expression Calculus and explicitly connect source quality, attention, transformation intensity and the Final Hit.
