# CAE Phase 0–7 State-Control Amendments v1.0

## Purpose

This amendment updates the existing Phase 0–7 governance program so state/transition control is verified before implementation authority is granted.

## Phase 0

Validate that the object constitution identifies:

- canonical state vs runtime state;
- event/history ownership;
- transition semantics;
- authorized operations;
- receipt requirements.

## Phase 1

Validate World / Audience / Guest / Context state models and their temporal semantics.

Required outcome:

```text
static profile ≠ current state ≠ historical evidence
```

## Phase 2

Validate Context Premise, Schema, Tension/Webhook, Affective State, Media Motive, Capacity/Maturity, and their temporal relationships.

StateM-inspired state-boundary thinking may inform implementation, but PostgreSQL remains authoritative.

## Phase 3

Validate Guest–Audience relations, congruence calculations, and transition rules for relational activation.

## Phase 4

Validate pressure-field states and Matrix of Edging transitions. No edge may be declared executable merely because it has a high proxy score.

## Phase 5

Validate human interview and evidence state transitions.

Constitutional boundary:

```text
Hypothesis → Provocation → Human Response → Authenticated Evidence
```

No downstream render transition is permitted to bypass authenticated evidence requirements where the PRD specifies them.

## Phase 6

Validate candidate, coalition, and Edge Product state models:

```text
candidate_generated
→ eligible / rejected
→ coalition_candidate
→ coalition_formed
→ edge_validated
```

Receipts must preserve lineage.

## Phase 7

Validate SemanticProgram, SFL stack, archetype, realization state, and transition into downstream composition.

SDA/SFL inherited registries remain canonical sources for their respective objects.

## Phase promotion consequence

A phase cannot reach `BROWNFIELD_VALIDATED` without a state/relation/event reconciliation matrix.

A phase cannot reach `SPEC_READY` without transition contracts.

A phase cannot reach `VERIFIED` without transition receipts and reality-contact evidence appropriate to the claim.
