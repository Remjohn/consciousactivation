# Phase 5 Object Definition Grammars

These are object-specific semantic writing protocols. They do not authorize generic safety language, licensing language, or premature content sanitization. Their purpose is precision, lineage, and anti-centroid preservation.

## InterviewBrief grammar
GENUS → a derived planning artifact. DIFFERENTIA → compiles an activation opportunity into a human-first inquiry plan without deciding the Guest's answer. FUNCTION → determines what evidence the session seeks. BOUNDARY → not a transcript and not a conclusion.

## InterviewQuestion grammar
GENUS → a typed communicative instruction to a human. DIFFERENTIA → declares a specific inquiry operation against a current evidence state. FUNCTION → elicits a useful response. BOUNDARY → must not encode an unsupported answer as if it were established.

## GuestResponse grammar
GENUS → immutable source evidence from a human interaction. DIFFERENTIA → directly records what the Guest expressed in the session. FUNCTION → provides first-party evidence. BOUNDARY → not an interpretation or semantic summary.

## EvidenceSpan grammar
GENUS → a selected fragment of source evidence. DIFFERENTIA → isolates a bounded segment because it carries a candidate evidentiary function. FUNCTION → make evidence retrievable and referenceable. BOUNDARY → selection does not itself authenticate the claim.

## AuthenticatedEvidence grammar
GENUS → a promoted evidence artifact. DIFFERENTIA → combines source lineage with an explicit authentication status and bounded interpretation. FUNCTION → authorize downstream reasoning. BOUNDARY → authentication does not mean universal truth; it means the evidence satisfies the declared project-level evidentiary standard for its intended use.

## AuthenticationDecision grammar
GENUS → a decision artifact. DIFFERENTIA → classifies whether a candidate claim may be treated as authenticated, provisional, ambiguous, contradicted, or unsupported. FUNCTION → control downstream use. BOUNDARY → never overwrites source evidence.

## AntiLeadingAssessment grammar
GENUS → a validator report. DIFFERENTIA → evaluates the question itself for response contamination. FUNCTION → protect human agency and evidentiary quality. BOUNDARY → must not judge whether the Guest's answer is desirable.

## AntiCentroidPatrolResult grammar
GENUS → an adversarial validator report. DIFFERENTIA → detects flattening between source response and downstream representation. FUNCTION → preserve specificity, tension, contradiction, and idiosyncratic language. BOUNDARY → anti-centroid does not mean anti-clarity.

## InterviewReceipt grammar
GENUS → an immutable execution trace. DIFFERENTIA → links Phase 4 activation through human response to authenticated evidence. FUNCTION → reproducibility and auditability. BOUNDARY → receipt data does not become semantic evidence merely because it exists.
