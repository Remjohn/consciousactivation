# Phase 7 Routing Protocol

## Routing dimensions

Phase 7 uses the 4D audience routing state where relevant:

1. Semantic State — active tensions/schema activation
2. Affective State — arousal × valence
3. Media Motive — escape / discovery / status / processing
4. Capacity / Maturity — depth tolerance

These do not replace the Edge Product. They condition how the Edge is carried.

## Routing equation

Conceptually:

```text
Structural Opportunity
= Edge Product × Archetype Fit × State Fit × Capacity Fit
```

This is a design abstraction, not necessarily a production scalar.

## Rules

- A high-charge Edge may require a lower-intensity delivery stack when audience state makes direct exposure counterproductive.
- Escape/Discovery routing may alter perceptual entry path while preserving the underlying semantic force.
- Processing routing can permit more direct edge expression.
- Status routing may encode force through comparison structure.

## Important boundary

Routing changes the **delivery path**, not the semantic source truth.

The same Edge Product may appear in multiple archetypes/states with different perceptual realization profiles.
