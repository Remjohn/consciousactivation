# Phase 7 Crosswalks

## Required maintained mappings

### Edge → Archetype
Defines which structural containers commonly preserve each Edge class.

### Archetype → SFL Family
Defines admissible and recommended perceptual families for each structural carrier.

### Archetype → Depth Profile
Defines default composition-depth options and incompatible combinations.

### Representation Geometry → SFL Profile
Maps directional representation to perceptual constraints.

### Audience Capacity → Archetype Depth
Maps maturity/depth tolerance to allowable structural and perceptual complexity.

### Director Directive → Contract Dimension
Maps common human instruction types to the contract fields they can modify.

## Crosswalk law

Crosswalks are maintained relationship objects, not hidden prompt heuristics.

Each mapping should include:
- source object
- target object
- relationship type
- confidence
- evidence / rationale
- version
- owner
- status

A runtime agent may retrieve a crosswalk, but cannot permanently mutate it without the canonical governance path.
