# Phase 7 Functional Requirements Inventory

## FR-07-01 Archetype Registry Consumption
The system SHALL retrieve canonical archetype definitions and contracts through authorized query surfaces.

## FR-07-02 Archetype Eligibility
The system SHALL reject structurally incompatible archetypes before selection.

## FR-07-03 Archetype Selection
The system SHALL select a carrier using typed criteria and preserve rejected alternatives.

## FR-07-04 SFL Canonical Registry
The system SHALL maintain versioned canonical SFL families and functions.

## FR-07-05 SFL Runtime Stack
The system SHALL compile a bounded context-specific SFL stack from canonical functions.

## FR-07-06 Influence Alignment
The system SHALL evaluate SFL use against declared alignment policies.

## FR-07-07 Composition Depth
The system SHALL bind a valid depth profile without converting complexity into ornament.

## FR-07-08 Director Note Compilation
The system SHALL convert approved human prose directives into typed JIT directives.

## FR-07-09 Semantic Program
The system SHALL compile a versioned SemanticProgram with complete upstream lineage.

## FR-07-10 Anti-Centroid Patrol
The system SHALL detect and route structural/perceptual centroid drift.

## FR-07-11 Typed Errors
The system SHALL classify failures into the Phase 7 error taxonomy.

## FR-07-12 Receipts
The system SHALL emit immutable receipts for decisions and validation.

## FR-07-13 Brownfield Compatibility
The implementation SHALL preserve existing archetype/SFL/primitive registries where canonical and migrate only through versioned adapters.

## FR-07-14 Phase Boundary Enforcement
The system SHALL prevent Phase 7 from emitting renderer-specific scene instructions.

## FR-07-15 Human Auditability
A human operator SHALL be able to inspect why a specific archetype and SFL stack were chosen.
