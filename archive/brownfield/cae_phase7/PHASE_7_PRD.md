# PRD-P07 — Archetype Containers, SFL Perceptual Delivery & Semantic Program Compilation

## 1. Purpose

Phase 7 is the structural/perceptual compiler of the Conscious Activation Engine. It receives a validated Edge Product and determines the admissible structural carrier, the perceptual modulation stack, the composition-depth profile, and the typed semantic program that Phase 8 can materially realize.

The central distinction is:

```text
Edge Product ≠ Archetype Container ≠ SFL Function ≠ Semantic Program ≠ Scene
```

The Edge Product answers **what force must be delivered**.  
The Archetype Container answers **what structural form can carry that force**.  
SFL answers **how the force should be perceptually experienced**.  
The Semantic Program answers **what the downstream realization engine is authorized to construct**.

## 2. Inputs

Required:
- validated Edge Product
- Coalition lineage and receipt
- relevant audience/guest/context state references
- SDA runtime packets and reports
- canonical archetype registry
- canonical SFL registry
- primitive-to-archetype and archetype-to-SFL crosswalks
- Director Note / human directive payload where present

Optional:
- performance memory
- archetype benchmark history
- SFL benchmark history
- previous accepted Semantic Programs
- platform/format target constraints

## 3. Processing stages

### Stage A — Archetype Eligibility
Identify structural carriers capable of preserving the Edge Product without semantic dilution.

### Stage B — Container Selection
Score eligible archetypes by semantic fit, structural capacity, routeability, anti-genericity profile, audience maturity, and Director constraints.

### Stage C — Contract Binding
Load the archetype's structural invariants, disallowed distortions, required phases, and downstream obligations.

### Stage D — SFL Resolution
Retrieve canonical SFL functions and assemble a bounded runtime stack. The stack must preserve semantic direction while shaping uptake, rhythm, symbolic density, contrast, and memorability.

### Stage E — Composition Depth
Select applicable depth mechanics such as repetition-with-variation, layered interpretation, rhythmic structure, and strategic ambiguity. These remain delivery intelligence, not existential ontology.

### Stage F — Perceptual / Directional Validation
Validate that perceptual modulation does not corrupt semantic direction and that the program does not collapse toward generic centroid behavior.

### Stage G — JIT Semantic Program Compilation
Compile all approved decisions into a typed `SemanticProgram` and a downstream-facing `JITDirectiveSet`.

### Stage H — Receipt
Persist source lineage, selected container, rejected alternatives, SFL stack, validations, human directives, and compile outcome.

## 4. Archetype law

An archetype is a canonical structural grammar / carrier. It is not a platform format and not a style preset. The same archetype may be realized through several output formats while preserving structural invariants.

Where a proposed archetype cannot preserve the Edge Product, it is ineligible even if its historical performance is strong.

## 5. SFL law

SFL canonical objects include:
- function families
- function definitions
- influence alignment policies
- perceptual metrics
- adversarial perceptual failure assets
- maintained crosswalks

Runtime stacks are dynamic and must be traceable to those canonical definitions.

## 6. Human directive law

Human Director Notes are authoritative intent-bearing source material. They are parsed into typed directives such as:
- perceptual intent
- structural preference
- forbidden effect
- emphasis preference
- rhythm preference
- tone/mood instruction
- preservation instruction

A directive can constrain or refine a compilation, but cannot authorize an impossible contract or mutate a canonical definition in place.

## 7. Phase boundary

Phase 7 ends with a validated, typed SemanticProgram. It does not choose concrete scene components, spatial coordinates, asset IDs, keyframes, transitions, audio clips, or executable video operations. Those belong to Phase 8+.
