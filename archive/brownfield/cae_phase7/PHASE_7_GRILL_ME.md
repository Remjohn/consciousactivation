# Phase 7 Grill-Me — Archetype, SFL & Semantic Program Compiler

Interview the architect one question at a time until Phase 7 is sufficiently specified for implementation.

## Protocol

1. Ask ONE question at a time.
2. Explore existing source files/code/registries first; do not ask questions answerable from project evidence.
3. Every recommendation must contain a substantive rationale grounded in the current project architecture.
4. Surface at least one collision between existing constraints.
5. Do not use generic “best practice” as the primary justification.
6. Recommended answers must preserve the Anti-Centroid Law: do not equate safety, politeness, moderation, or conventionality with quality.
7. If an ambiguity affects canonical ontology, stop and resolve it before downstream implementation.
8. Distinguish canonical definition changes from runtime compilation choices.

## Required branch order

### Branch A — Archetype ontology
- What exactly is an ArchetypeContainerDefinition?
- Are the existing archetype families and archetypes duplicated under multiple names?
- What is canonical vs template/module vs instance?
- Which archetypes can carry multiple Edge classes?

### Branch B — Archetype routing
- What makes an archetype eligible?
- What wins when historical performance conflicts with semantic fit?
- How should audience state modify eligibility vs only execution?

### Branch C — SFL ontology
- Which SFL objects are canonical?
- Which current 120 associations are functions vs metrics vs policies vs failure assets?
- What is the minimum executable representation of an SFL function?

### Branch D — Human directives
- Which prose directives become typed contracts?
- What priority hierarchy governs conflicts?
- When may a Director Note trigger escalation rather than runtime override?

### Branch E — SemanticProgram
- What must Phase 8 receive?
- What must Phase 7 explicitly refuse to encode?
- Which fields guarantee semantic preservation?

### Branch F — Validation and anti-centroid
- What constitutes perceptual deadness?
- What counts as false depth?
- Which forms of “safety” are legitimate constraints versus centroid injections?

### Branch G — Brownfield migration
- Which existing archetype/SFL registries become canonical?
- What adapters are required?
- What legacy outputs need migration vs preservation?
