# Phase 6 Functional Requirement Inventory

FR-P06-01 Semantic Field Assembly  
Construct the runtime invariant and geometry field from authenticated evidence.

FR-P06-02 Primitive Eligibility Retrieval  
Retrieve only primitives admissible for the current semantic field and context.

FR-P06-03 Candidate Generation  
Generate multiple evidence-specific candidates before selecting a coalition.

FR-P06-04 Candidate Assessment  
Score candidates across fidelity, charge, recognition, prediction violation, costly exposure, articulation, independence, and routeability.

FR-P06-05 Candidate Rejection Logging  
Persist typed rejection reasons and evidence lineage.

FR-P06-06 Compatibility Evaluation  
Evaluate synergy, antagonism, cancellation, redundancy, and family saturation.

FR-P06-07 Coalition Formation  
Assemble sparse weighted coalitions from surviving candidates.

FR-P06-08 Coalition Validation  
Validate ranges, lineage, geometry, routeability, and directional integrity.

FR-P06-09 Edge Product Derivation  
Derive the emergent tension object from the selected coalition.

FR-P06-10 Edge Distinctiveness  
Compare candidate Edge Products against prior and nearest-neighbor edges.

FR-P06-11 Anti-Centroid Patrol  
Detect semantic flattening at candidate, coalition, and edge levels.

FR-P06-12 Hard-Negative Evaluation  
Stress-test coalitions against deceptive near-neighbor failures.

FR-P06-13 Receipt Generation  
Persist candidate, coalition, and semantic compilation receipts.

FR-P06-14 Controlled Agent Query Surface  
Expose SQL / JSONB functions and views instead of arbitrary database reasoning.

FR-P06-15 Error Taxonomy Routing  
Classify failures and select a repair path.

FR-P06-16 Registry-Gap Escalation  
Identify repeated unsupported operations that may require a new canonical primitive.

FR-P06-17 Benchmark Memory  
Store coalition and edge outcomes for later retrieval and ranking.

FR-P06-18 Brownfield Adapter  
Reuse existing primitive, SDA, Matrix of Edging, and receipt components where available.
