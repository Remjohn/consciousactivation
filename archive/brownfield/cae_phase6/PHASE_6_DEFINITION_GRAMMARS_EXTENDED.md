# Phase 6 Extended Object Constitution Rules

All Phase 6 objects inherit the global Object Constitution, but each object class has a distinct definition grammar.

## PrimitiveCandidate
Must define activation of a canonical operator against a particular evidence field.

## CandidateAssessment
Must define evaluation, not truth.

## CoalitionCandidate
Must define a proposed multi-operator geometry before final selection.

## CoalitionSignature
Must define an accepted geometry with explicit weights and constraints.

## EdgeProduct
Must define an emergent force object and its semantic boundary.

## SemanticCompilationReceipt
Must define what the compiler did, what it selected, what failed, and what evidence supports the result.

### Global rule

**Role before schema.**

If an object cannot be assigned a clear architectural role, its schema must not be frozen.

### Anti-centroid constitutional rule

Definitions must not contain unnecessary licensing, censorship, or generic-safety clauses that weaken the object's semantic purpose. Boundary statements should prevent category confusion, fabrication, or state mutation—not prohibit legitimate expression because it is intense, unusual, asymmetric, controversial, or difficult.

### Precision rule

The definition should be long enough to establish:
- genus,
- differentia,
- function,
- boundary,
- downstream consequence.

Do not use a universal word count.
