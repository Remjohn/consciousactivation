# PRD-P06 — Semantic Candidate Compilation, Coalition Formation & Edge Products

## 1. Purpose

Phase 6 is the semantic force compiler of the Conscious Activation Engine. It converts authenticated human evidence into a bounded set of evidence-grounded transformation candidates, selects a sparse compatible coalition, and derives the Edge Product that represents the actual executable tension produced by the coalition.

## 2. Architectural claim

Primitive registries provide reusable capabilities. Authenticated evidence provides the local source material. Phase 6 is the compiler that determines which capabilities are legally admissible for this evidence and how they combine.

The governing distinction is:

```text
Primitive Definition ≠ Primitive Candidate ≠ Coalition ≠ Edge Product
```

A Primitive Definition is canonical.
A Primitive Candidate is contextual.
A Coalition is a selected combination.
An Edge Product is the emergent tension object.

## 3. Inputs

Required:
- authenticated evidence
- evidence lineage
- Guest/Audience relational context
- active Contextual State
- relevant SDA field
- canonical primitive registry
- relevant crosswalks
- current Matrix of Edging output

Optional:
- historical coalition receipts
- previous edge benchmarks
- SFL crosswalk metadata
- archetype compatibility data for routeability only

## 4. Processing stages

### Stage A — Semantic Field Construction
Determine active invariants, contextual semantic pressures, and relevant representation/archetypal geometry.

### Stage B — Candidate Generation
Query the primitive registry and generate evidence-specific candidates.

### Stage C — Eligibility
Reject candidates that violate source, family, range, evidence, role, or contextual constraints.

### Stage D — Survival
Score candidates for evidence fidelity, charge, recognition, distinctiveness, compositional independence, and routeability.

### Stage E — Compatibility
Evaluate synergy, antagonism, redundancy, family saturation, cancellation, and illegal combinations.

### Stage F — Weighting
Assign explicit coalition weights and verify admissible ranges.

### Stage G — Routeability
Determine whether the coalition can produce an executable downstream semantic program.

### Stage H — Edge Product Derivation
Derive the emergent tension product represented by the coalition.

### Stage I — Validation / Receipt
Persist decisions, reasons, lineage, failed candidates, and measured handoff conditions.

## 5. Anti-centroid requirement

A generic, over-smoothed, consensus-like candidate MUST NOT receive a higher survival score merely because it appears safer, more conventional, or more broadly acceptable. Meaningful tension is preserved unless evidence or an explicit contract requires transformation.

## 6. Phase boundary

Phase 6 ends with an authenticated, routeable semantic force object. It does not decide how that force becomes:
- story container
- archetype
- scene
- visual syntax
- sonic arrangement
- executable media IR

Those belong to subsequent phases.
