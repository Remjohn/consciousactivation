# Object Class Matrix

| Artifact Class | Core Definition Grammar | Typical Lifecycle | Primary Question |
|---|---|---|---|
| Entity | Genus + identity + continuity + function + boundary | Canonical | What enduring thing exists? |
| Value Object | value semantics + equality + domain + range | Canonical / derived | What value is represented? |
| Relation | source + relation + target + temporal/evidence semantics | Canonical / dynamic | How are objects related? |
| State | subject + condition + time + transition + history | Dynamic | What condition is active now? |
| Event | occurrence + actors + time + payload + consequence | Immutable / event | What happened? |
| Evidence | source + observation + provenance + status + limits | Immutable evidence | What supports this claim? |
| Canonical Ontology | genus + differentia + domain meaning + boundary + relations | Canonical | What stable concept exists? |
| Structural Grammar | purpose + inputs + topology + combination rules | Canonical | How may concepts combine? |
| Operator / Primitive | transformation + substrate + activation + range + evidence | Canonical definition / dynamic activation | What operation can be performed? |
| Policy / Contract | jurisdiction + obligations + permissions + prohibitions + priority | Canonical | What is allowed or required? |
| Derived Artifact | inputs + derivation + result + lineage + confidence | Derived | What did the system infer/compile? |
| Execution Packet | purpose + typed payload + validity + lineage + consumer contract | Dynamic | What must move through runtime? |
| Adversarial Asset | positive + deceptive negative + divergence + mutation + expected verdict | Benchmark | What near-failure must we detect? |
| IR | source semantics + normalized structure + execution intent + lowering | Derived / versioned | What executable meaning has been compiled? |
| Longitudinal Memory | subject + phenomenon + observation sequence + aggregation + update rule | Dynamic / memory | What changed across time? |
