# Canonical Ontology Object Definition Grammar Protocol

## Artifact class

`CANONICAL_ONTOLOGY`

## Purpose

Defines slow-changing conceptual categories that constitute the system's authoritative semantic vocabulary.

## Definition grammar

Use:

**Genus + Differentia + Domain Meaning + Boundary + Relations + Tension/Variation Space + Canonical Function + Validation Relevance**

## Definition standard

Definitions should normally be 120–220 words or longer when necessary. Complexity, not word count, determines sufficiency.

## Required semantic dimensions

- canonical identity
- mechanistic definition
- inclusion criteria
- exclusion criteria
- nearest neighbors
- adjacent concepts
- conflict relations
- canonical dimensions
- provenance / evidence basis
- governance authority
- versioning policy

## Example classes

`ExistentialInvariant`, `RepresentationGeometry`, other stable semantic ontology objects.

## Hard negatives

- canonical ontology object that is actually a runtime state
- derived hypothesis presented as canonical
- primitive definition absorbed into ontology
- metric mistaken for ontology

## Constitutional law

**Canonical ontology changes slowly, deliberately, and under explicit authority.**
