# Structural Grammar Definition Protocol

## Artifact class

`STRUCTURAL_GRAMMAR`

## Purpose

Defines reusable rules for arranging canonical semantic units into valid structural configurations.

## Definition grammar

Use:

**Structural Purpose + Inputs + Topology + Ordering/Transformation Logic + Compatibility + Forbidden Configurations + Validation Consequence**

## Examples

`ArchetypalGeometry`, `SpeciesCompositionGrammar`, composition grammars.

## Definition must establish

- what semantic units it accepts
- how they are organized
- required topology
- sequencing or ordering logic
- degrees of freedom
- forbidden or unstable combinations
- how deviations are detected

## Distinction

A structural grammar defines **how components may combine**. It is not itself a particular runtime composition.

## Hard negatives

- structural grammar reduced to a label such as “Hero”
- runtime instance treated as canonical grammar
- format treated as semantic grammar without structural rules
