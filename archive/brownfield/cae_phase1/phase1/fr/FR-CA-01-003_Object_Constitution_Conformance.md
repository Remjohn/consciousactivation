# FR-CA-01-003 — Object Constitution Conformance

## Requirement
Every object promoted to canonical status SHALL conform to the Object Constitution and the appropriate class-specific definition grammar.

## Required Dimensions
Identity, class, plane, role, definition, boundary, neighbors, taxonomy, lifecycle, attributes, relations, state, events, provenance, invariants, authority, operations, validators, error taxonomy, storage, consumers, questions answered, examples, hard negatives, version history.

## Anti-Centroid Requirement
Definition grammars MUST remain precise without adding generic permission/censorship clauses unless they are part of the object's actual ontology.

## Acceptance Criteria
- Definition states genus/differentia/function/boundary.
- Class-specific grammar is used.
- Nearest-neighbor distinctions are explicit where confusion is plausible.
- Runtime behavior is not smuggled into canonical definition.
- Hard negatives exist for materially ambiguous boundaries.
