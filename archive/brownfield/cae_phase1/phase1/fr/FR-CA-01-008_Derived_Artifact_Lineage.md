# FR-CA-01-008 — Derived Artifact Lineage

## Requirement
Derived artifacts SHALL preserve enough lineage to explain and, where practical, reproduce their derivation.

## Core Derived Types
Tension/Webhook, PrimitiveCandidate, Coalition, EdgeProduct, SemanticProgram, CompositionIR, VideoEditProgram.

## Acceptance Criteria
Every derived artifact can identify the upstream evidence/state, canonical definitions, programs/contracts, versions, and execution context used to produce it.
