# FR-CA-02-012 — Audience Affective Media Motive and Maturity Model

Audience routing intelligence MUST represent affective state, media motive, and maturity/capacity as distinct dimensions.

## Constraints
Affective state uses arousal × valence; media motive uses the maintained taxonomy; maturity is evidence-driven and temporally evolving.

## Implementation Principle
These dimensions may interact during planning but MUST NOT be collapsed into one scalar or label.

- Object Constitution fields are defined or marked pending.
