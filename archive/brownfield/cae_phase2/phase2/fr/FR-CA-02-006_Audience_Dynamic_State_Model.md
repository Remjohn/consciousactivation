# FR-CA-02-006 — Audience Dynamic State Model

## Requirement
AudienceState MUST represent a time-bounded configuration of an Audience at an observation interval.

## Constraints
Semantic, affective, media-motive, and capacity/maturity dimensions MUST remain separately addressable.

## Implementation Principle
State history MUST be append-preserving; current state is a derived view, not an overwriting mutation.

## Acceptance Criteria
- Canonical identity/ownership is explicit.
- Object Constitution fields are defined or marked pending.
- Provenance and lifecycle are testable.
- No silent flattening of evidence into unsupported canonical claims.
- Brownfield status is recorded before replacement.
