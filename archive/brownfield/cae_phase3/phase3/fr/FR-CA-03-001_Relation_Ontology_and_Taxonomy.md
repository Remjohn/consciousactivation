# FR-CA-03-001 — Relation Ontology and Taxonomy

## Requirement
Define and register all relational artifact classes and relation types used by CAE.

## Acceptance
- each relation has explicit source and target roles;
- directionality is explicit;
- temporal semantics are explicit;
- relation class is distinct from assessment, state, event, and candidate;
- near-neighbor distinctions are documented.

## Constraints
No relation may be created solely for storage convenience.
