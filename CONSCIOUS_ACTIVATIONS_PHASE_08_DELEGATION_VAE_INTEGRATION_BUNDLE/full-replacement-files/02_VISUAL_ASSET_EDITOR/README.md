# Conscious Activations Visual Asset Editor

The VAE is the product that materially realizes typed visual demands. Phase 8 provides a
bounded local development core for exact Delegation RC4 consumption, provider-neutral plans,
capability routing, Dynamic Workcells, artifact storage, queue/worker execution, technical
evaluation, repair, memory projection, and Control Tower evidence.

Run a reference demonstration from the repository root:

```bash
PYTHONPATH=packages/ca_contracts/src:packages/ca_runtime/src:packages/ca_delegation_rc4/src:04_ACTIVATIVE_INTELLIGENCE_RUNTIME/src:05_ATOMIC_HARNESS_PIPELINE/src:06_INTERVIEW_EXPRESSION/src:02_VISUAL_ASSET_EDITOR/src \
python -m cmf_vae --repo . demo --output-dir .conscious-activations/phase8-demo
```

The reference path is explicitly not production provider proof.
