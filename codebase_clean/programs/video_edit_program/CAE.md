# Video Edit Production Program — CAE Authority Specification

## Mission
Coordinates end-to-end source-led video editing, word boundary EDL compilation, VideoEditProgram compilation, export binding compilation (Remotion, HyperFrames), and real FFmpeg video rendering with dual-axis QA and backend-authoritative operator release receipts.

## Four-Lane Authority Separation
- **COMMANDER**: Admits semantic material, authorizes release receipts, executes state repair.
- **HUNTER**: Registers physical source media assets, extracts verbatim spoken timing and evidence spans from authentic evidence records.
- **COMPOSER**: Compiles `WordBoundaryEdl`, `VideoEditProgram`, export bindings, and executes FFmpeg physical rendering pass.
- **ANALYST**: Executes dual-axis QA (Semantic QA vs Render QA) verifying verbatim spoken fidelity, wrong-reading locks, A-roll spine integrity, ffprobe stream health, and visual cut frames.

## Invariants
1. **Source Fidelity**: All spoken dialogue in the A-roll spine must match authentic interview source hashes.
2. **Anti-Synthetic**: Synthetic candidates and mock media are rejected fail-closed.
3. **Dual-Axis QA**: Semantic QA and Render QA are evaluated independently.
4. **Backend Release Authority**: Release receipts are cryptographic, signed by an authorized operator actor, and cannot be bypassed.
