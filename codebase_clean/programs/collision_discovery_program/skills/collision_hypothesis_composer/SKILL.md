# Collision Hypothesis Composer Skill

## Purpose
Synthesizes verified 4-world inputs (World Signal, Audience Tension, Guest Authority, Matrix of Edging) into grounded, typed `CollisionHypothesis` records and packages them into portfolios with diversity signatures.

## Rules
- Flat skill only: no subagent delegation, no skill-to-skill invocation.
- Construct explicit, unambiguous bridge statements binding all four worlds.
- Compute canonical SHA-256 diversity signatures across editorial axes.
- Preserve source lineage without mutating underlying guest or audience records.
