# Matrix of Edging Evaluator Skill

## Purpose
Evaluates candidate semantic collisions against the Matrix of Edging (hidden pressure, surviving edge, identity gap, desired recognition) and enforces non-negotiable falsification and anti-cliché gating.

## Rules
- Flat skill only: no subagent delegation, no skill-to-skill invocation.
- Verify that every candidate declares an explicit structural relation type (`ANALOGY`, `INVERSION`, `PARADOX`, `SYSTEMS_LENS`, `COUNTER_POSITION`).
- Enforce strict falsification criteria (refuting observation, disconfirming testimony, boundary limitation).
- Apply anti-cliché and trope penalties; quarantine generic buzzword combinations.
