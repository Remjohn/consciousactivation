# Visual Prompt + Asset Annotation Program Instructions

## Operational Workflow
1. **Admit Semantic Program (`COMMANDER`):**
   - Verify active workspace and authentic operator authorization.
   - Validate that the program is non-synthetic and that evidence quotes match SHA-256 hashes.
2. **Extract Visual Requirements (`HUNTER`):**
   - Extract scene obligations, subject definitions, and recognition targets.
   - Assign somatic effects (e.g., tension escalation vs cognitive resolution) and activative functions.
3. **Annotate Asset Packages (`ANALYST`):**
   - Catalog primary evidence and E/D-roll media inserts.
   - Verify rights clearance status (`CLEARED_COMMERCIAL`, `PUBLIC_DOMAIN`, etc.) and SHA-256 file hashes.
4. **Compile Visual Demands (`COMPOSER`):**
   - Formulate positive generative prompts and negative prompt constraints embedding wrong-reading locks.
   - Compile provider-neutral `VisualAssetDemandContract` structures with composition bounding boxes.
5. **Approve Visual Package (`COMMANDER`):**
   - Review complete package snapshot.
   - Authoritatively sign and emit `VisualPackageReceipt` for downstream VAE and composition execution.
