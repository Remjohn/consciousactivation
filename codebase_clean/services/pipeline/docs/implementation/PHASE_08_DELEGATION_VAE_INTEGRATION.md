# Phase 8 Pipeline–Delegation–VAE Integration

## Implemented boundary

The Pipeline consumes the exact local unsigned `delegation-contracts@1.1.0-rc.4` release without copying or redefining its schemas. `VisualDelegationService` compiles a provider-neutral Visual Asset Demand from approved source and semantic references, validates returned Asset Results, and creates a separate Result Acknowledgement.

## Source and semantic lineage

The demand preserves:

- Canonical Interview Source Package;
- Reaction Receipts;
- Expression Moments;
- derivative semantic program;
- approved Final Script;
- Primitive Coalition Contract;
- archetype coalition;
- Activation Transfer Contract;
- Content Harness and category/format profiles;
- wrong-reading locks.

## Ownership

Pipeline owns demand compilation, result validation, and downstream acknowledgement. VAE owns production planning, provider/runtime binding, materialization, evaluation implementation, and repair. AIR and the active Harness remain semantic authority.

## Development evidence

The Phase 8 reference demonstration proves:

```text
provider-neutral demand
→ RC4 validation
→ VAE admission
→ reference visual artifact
→ Asset Result
→ Pipeline acknowledgement
```

The visual artifact is generated by an explicitly labeled reference provider. No real SAM3, Lucida, ComfyUI worker, or GNM execution is claimed.
