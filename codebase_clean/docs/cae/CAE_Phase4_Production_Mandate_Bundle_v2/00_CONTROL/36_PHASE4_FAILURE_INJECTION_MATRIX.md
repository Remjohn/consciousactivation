# Phase 4 Failure Injection Matrix

At minimum test:
- candidate evidence missing
- wrong source lineage
- operator rejects candidate
- script approval missing
- asset package missing
- VAE delegation unavailable
- render failure
- corrupt media
- semantic QA rejection
- stale artifact version
- duplicate render
- release approval missing
- ship failure
- outcome write failure
- resumed pipeline after interruption
- operator edits/rejects after downstream derivative exists

Expected behavior must be explicit: block, repair, resume, reconcile, or fail safely.
