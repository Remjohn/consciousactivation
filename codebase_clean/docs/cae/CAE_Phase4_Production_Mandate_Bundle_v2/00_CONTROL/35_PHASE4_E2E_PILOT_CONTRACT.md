# Phase 4 End-to-End Pilot Contract

The final pilot must use one controlled but real Workspace/Guest and a real evidence package.

Minimum chain:
Workspace
→ Guest
→ Audience
→ research/context
→ CollisionHypothesis
→ InterviewBrief
→ InterviewResponse
→ evidence
→ candidate
→ operator selection
→ SemanticProgram
→ script
→ visual demand
→ at least one real production derivative
→ render
→ QA
→ approval
→ release/ship
→ Outcome.

The pilot must record all state transitions, agent/lane activity, Skills, operations,
artifacts, receipts, operator decisions, failures and recovery.
