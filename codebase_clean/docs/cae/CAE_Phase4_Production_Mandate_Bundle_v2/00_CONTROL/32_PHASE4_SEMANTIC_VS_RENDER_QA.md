# Phase 4 Semantic vs Render QA

Production QA has two independent dimensions.

## Semantic QA
- source fidelity
- speaker authenticity
- evidence support
- intended recognition
- narrative role
- wrong-reading prevention
- archetype/harness compatibility
- semantic asset annotation integrity

## Render QA
- media validity
- timing
- audio
- captions
- frame integrity
- resolution
- transitions
- file/container validity
- deterministic render reproducibility

A render may pass while semantic QA fails.
A semantic plan may pass while render QA fails.
Acceptance requires both where applicable.
