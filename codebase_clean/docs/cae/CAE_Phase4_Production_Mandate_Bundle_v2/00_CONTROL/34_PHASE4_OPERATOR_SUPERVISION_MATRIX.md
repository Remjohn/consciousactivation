# Phase 4 Operator Supervision Matrix

| Decision point | Program state | Human authority | Allowed decisions | Required evidence | Resume behavior |
|---|---|---|---|---|---|

Required decision classes:
- candidate selection
- storyboard approval
- script approval
- visual approval
- render QA approval
- release authorization
- repair/regenerate
- reject/archive

Operator approval is a backend-authoritative state transition, not a chat message.
