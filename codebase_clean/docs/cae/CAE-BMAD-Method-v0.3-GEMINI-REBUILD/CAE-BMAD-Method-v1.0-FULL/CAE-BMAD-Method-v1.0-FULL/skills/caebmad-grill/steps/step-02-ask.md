# Grill Step 02 — Ask One Question

Present exactly one unresolved product/constitutional question.

Use this order:

1. What is being decided?
2. Why must it be decided now?
3. What evidence exists?
4. What are the meaningful options?
5. Which option is recommended and why?
6. What happens if the operator chooses the alternatives?
7. Ask the single question.

Do not append a second question.

After the answer is received, update the decision ledger before selecting the next question.
