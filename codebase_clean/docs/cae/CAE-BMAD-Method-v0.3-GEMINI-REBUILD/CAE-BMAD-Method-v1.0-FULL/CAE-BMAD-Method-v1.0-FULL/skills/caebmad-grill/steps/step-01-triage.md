# Grill Step 01 — Triage

Determine whether the unresolved question actually requires human judgment.

### Resolve automatically when:

- exact code behavior can answer it;
- an approved document already answers it;
- the research corpus contains authoritative evidence;
- the question is only a formatting or mechanical concern.

### Human boundary

Ask the operator only when the choice affects:

- product identity
- intended user outcome
- constitutional priorities
- acceptable trade-offs
- scope
- product-level non-goals
- explicit approval of a contradiction
- irreversible direction

### Output

Create/update the decision queue with:

- question ID
- decision
- evidence
- options
- recommended option
- consequences
- whether human input is required
