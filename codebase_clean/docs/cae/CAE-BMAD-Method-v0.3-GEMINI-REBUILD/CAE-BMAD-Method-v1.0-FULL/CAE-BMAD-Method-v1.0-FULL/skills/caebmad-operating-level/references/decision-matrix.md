# Operating-Level Decision Matrix

| Condition | Direction |
|---|---|
| unfamiliar repository | down |
| unfamiliar domain | down |
| weak evidence | down |
| high-risk behavior | down |
| exact implementation behavior needed | down |
| performance/details dominate | down |
| repeated stable sequence | up |
| stable contracts | up |
| strong evidence | up |
| many artifacts share a sequence | up |
| reliable proof exists | up |

The selected level is a minimum, not an upper bound.
Escalate downward whenever an observation is surprising, contradictory, or insufficient to support the claim.
