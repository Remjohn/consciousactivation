# CAE-BMAD Artifact Governance

## Lifecycle

DRAFT
→ RESEARCHED
→ RECONSTRUCTED
→ GRILLED
→ APPROVED
→ IMPLEMENTED
→ VERIFIED
→ CANONICAL

A document can be:

- superseded
- deprecated
- contradicted

without being deleted.

## Completion rules

### File existence

Not completion.

### Frontmatter status

Necessary but not sufficient.

### Green test

Not production proof unless it contacts the real behavior being claimed.

### Canonical promotion

Requires explicit promotion plus traceability.

## Revision rules

When a product artifact changes:

1. identify the affected sources
2. identify downstream artifacts
3. identify implementation impact
4. identify changed decisions
5. preserve the old decision/history
6. update status and version
7. update the traceability map

## Research corpus completion

`research_complete: true` is permitted only when:

- target count is 216
- every source has a source ID
- all Tier-1 sources are verified or explicitly marked unavailable
- major historical branches are represented
- relevance scores are present
- authority classes are present
- lineage is present
- contradictions are recorded

## Product rewrite completion

The Product Brief is not final until:

- reconstruction is approved
- major operator/product concepts are captured
- important historical lineage has an explicit disposition
- unresolved constitutional decisions are either decided or explicitly accepted as open
