# Phase 3 Canonicalization Model

Canonicalization is treated as a first-class intelligence program, not summarization.

## Semantic chain

SOURCE
  ↓
EXTRACTION
  ↓
KNOWLEDGE CANDIDATE
  ↓
CANONICALIZATION
  ├── SAME
  ├── RELATED
  ├── SUBTYPE / SUPERtype
  ├── CONTRADICTORY
  └── DISTINCT
  ↓
CANONICAL KNOWLEDGE NODE
  ↓
CLUSTER / RELATIONSHIP
  ↓
RESEARCH SIGNAL
  ↓
CONTEXT PROJECTION
  ↓
STATE / HYPOTHESIS

## Protected source-bearing layers

These are not silently rewritten by a derived-expression repair:
- authenticated Guest source evidence
- historical Guest memory
- Guest identity/source record
- Audience Cognitive Islands when constitutionally protected
- immutable external research source evidence

## Mutable derived-expression layers

These may be versioned/recompiled with provenance:
- taxonomy/dimensions
- context matrices
- clusters
- relationship projections
- retrieval indexes
- activation coordinates
- semantic projections
- canonical wording/expression

## Required operations

Where supported by current authority:
- merge
- split
- supersede
- retract
- reclassify
- rename
- re-express
- rebuild projections

Every derived-expression change must preserve ancestry to protected source material.
A change to a canonical expression must invalidate/recompile affected downstream projections rather
than silently mutate protected source truth.
