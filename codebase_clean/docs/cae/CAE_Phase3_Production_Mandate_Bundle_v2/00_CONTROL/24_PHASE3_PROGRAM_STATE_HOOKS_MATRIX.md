# Phase 3 Program State + Hooks Matrix

For each Program M25–M35 record:
- state graph
- state-local context
- entry hook
- work body
- exit hook
- before-transfer checks
- repair route
- resume route
- operator gate
- artifact requirement
- receipt requirement

Program completion is never inferred from agent text. Completion requires state contract + postconditions +
artifact/receipt evidence and, where specified, operator authorization.
