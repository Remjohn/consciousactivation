# Gemini Execution Contract

`AUTHORITY → PREFLIGHT → BROWNFIELDS RECONCILIATION → PLAN → OPERATOR GATE → IMPLEMENT → DETERMINISTIC TEST → REALITY CONTACT → EVIDENCE → RECEIPT → CURRENT SYNC → STOP`

Gemini receives exactly one approved mandate at a time.

Before modifying code, Gemini must:
1. read all mandatory references;
2. inspect exact symbols and callers;
3. distinguish implementation truth, target truth and unresolved truth;
4. identify canonical authority and any duplicate;
5. write the required pre-flight artifact;
6. stop for Operator review when the mandate requires it.

No mandate may claim runtime integration from file existence or documentation.

Every important verifier needs a countertest.

Every reality-contact claim must include exact command, environment identity, run/aggregate IDs, state/version/hash, AgentInvocation/package/capsule hashes where applicable, receipt IDs and exact git SHA.

A green test suite is not production authorization.
