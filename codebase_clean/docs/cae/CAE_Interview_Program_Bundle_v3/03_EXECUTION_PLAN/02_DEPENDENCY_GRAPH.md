## Hard dependencies

- M02 cannot implement against an invented hypothesis schema.
- M03 cannot canonize primitive candidates that have not passed synthesis/promotion.
- M04 cannot change the existing Brief contract without a separate accepted spec update.
- M05 cannot persist feedback without identifying the owning authority.
- M06/M07 cannot assume a runtime answer-observation object exists; they must first inspect the live runtime seam.
- M08 cannot invent format/archetype identifiers.
- M09 cannot claim authenticated evidence merely from UI/API receipts.
- M11 cannot close unresolved ownership gaps by approximation.
