## 2. Acquisition Domain & Lineage Distinction Rules

1. **Strict Lineage Category Segregation (AC-02, FR-IP-007):**
   `EvidenceLineageKind` distinguishes between:
   - `GUEST_STATED_EVIDENCE`: Direct, empirical lived statements provided by the Guest.
   - `SYSTEM_INFERENCE`: Interpretations, sentiment classifications, or derived hypotheses generated by LLMs/heuristics.
   - `GUEST_VALIDATED_INTERPRETATION`: System inferences explicitly presented to and confirmed/corrected by the Guest.
   
   System inferences are strictly prohibited from being serialized or marked as authenticated guest facts.
2. **Receipt Existence Invariant (AC-01, FR-IP-007):**
   The mere existence of an API receipt or HTTP 200 does not authenticate evidence. `AcquisitionEvidenceRecord` rejects `is_authenticated=True` when `authentication_method == "unauthenticated_receipt"`.
3. **Hypothesis Immutability on Completeness Updates (AC-03, FR-IP-006):**
   An answer observation can transition information completeness (`PARTIAL` $\rightarrow$ `VERIFIED`) without altering, duplicating, or mutating upstream AIR hypothesis IDs, versions, or SHA256 hashes.
4. **Pre-Reconciliation Discrepancy Recording (AC-04):**
   Factual contradictions discovered during a turn are recorded in typed `DiscrepancyRecord` structures and attached to `SemanticAcquisitionObservation.discrepancy_refs` before triggering adaptive reconciliation actions.
5. **Differential Adaptive Routing (AC-05, FR-IP-005/006):**
   Observation dimensions directly trigger explainable next-question actions on the adaptive frontier:
   - Abstract / Generic slop $\rightarrow$ `DEEPEN`
   - Contradiction / Discrepancy $\rightarrow$ `RECONCILE`
   - Partial milestone coverage $\rightarrow$ `BROADEN`
   - Verified milestone evidence $\rightarrow$ `ADVANCE` (or terminal `CLOSE`)
6. **Lineage Preservation for Validated Interpretations (AC-06):**
   When a Guest explicitly confirms a prior system inference, the record is classified as `GUEST_VALIDATED_INTERPRETATION` and preserves a direct pointer `validated_from_inference_ref` back to the original inference.
7. **Derived Schema Conformance (AC-07):**
   `SemanticAcquisitionObservation` conforms strictly to `03_DERIVED_SCHEMAS.yaml` and is flagged `is_canonical = False`.
