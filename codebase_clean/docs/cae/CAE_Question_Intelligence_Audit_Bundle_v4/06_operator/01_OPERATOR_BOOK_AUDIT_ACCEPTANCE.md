# Operator Gate — Book Audit Acceptance

For each book, verify:

- [ ] Actual source identified and retained.
- [ ] PDF conversion manifest reviewed where applicable.
- [ ] Full-source read claim is supported.
- [ ] Audit distinguishes source claim / synthesis / CAE hypothesis.
- [ ] Candidate mechanisms are source-grounded.
- [ ] MCDA is explained rather than decorative.
- [ ] Answer transformation is concrete.
- [ ] Taxonomy novelty was examined rather than assumed away.
- [ ] No primitive YAML was created.
- [ ] Genericity / cliché / reward-hacking risks are explicit.

Operator outcome:
`ACCEPT` | `RETURN_FOR_REVIEW` | `SOURCE_FAILURE`

Only `ACCEPT` permits the book to enter the later cross-book clustering stage.
